# RightsWindow · 授权窗口编排与替换演练台

纯浏览器本地运行（React + TypeScript + Vite，无后端、无第三方运行时依赖）的
广告片 / 栏目片段授权窗口编排工具：按地区、渠道与当地时间查看节目段落的使用权，
编辑授权窗口与替代素材链，拖动演练时钟观察**生效前 / 临界时刻 / 失效后**的实际选材。

## 启动

```bash
npm install
npm run dev        # 开发服务器
npm test           # 全部测试（Vitest，node + jsdom）
npm run build      # 类型检查 + 生产构建
```

## 核心语义

- **绝对时刻**：所有窗口起止以带偏移 ISO-8601（如 `2026-09-18T20:00:00+08:00`）
  存储，内部统一为 epoch ms，杜绝跨时区歧义。
- **半开区间 `[start, end)`**：开始瞬间已生效，结束瞬间（零点切换）已失效；
  边界两侧均有测试。
- **替代链选材**：按链自上而下，第一个「地区 + 渠道 + 时刻」全部命中的素材胜出；
  链可降级到安全垫片，走完全链仍无素材则黑屏。
- **确定性**：同一输入重复演练结果完全相同；多窗口重叠时按
  “开始最早、窗口 id 字典序”裁决，并在路径中标注重叠。
- **时区**：录入按所选地区 IANA 时区（`Asia/Shanghai` / `Asia/Singapore` /
  `Europe/London`）解释为墙钟时间；正确处理伦敦夏令时秋跳（取较早瞬间）与春跳。

## 冲突体检

自动检测并给出可点击跳转的解释路径：窗口重叠（含渠道维度）、授权空档、
地区不匹配、替代链断裂、替代链循环、素材完全未授权。

## 内置案例

跨上海 / 新加坡 / 伦敦的品牌新品直播：品牌主片 → 区域版（本地解说）→ 安全垫片；
伦敦主片仅授权官网直播，OTT 大屏直接落到区域版。另含 4 个一键事故情景：
临时撤权、窗口重叠、替代链断裂、替代链循环。

## 编辑能力

- 授权窗口增删改：起止（当地时间录入）、素材、授权渠道（全部/指定）
- 替代链排序、增删与播出时段编辑
- 撤销 / 重做（Ctrl/⌘+Z、Ctrl/⌘+Shift+Z，最多 100 步）
- 草稿自动保存（localStorage），刷新恢复
- 命名情景快照（编排 + 时钟一起保存/载入）
- 一键复位到内置健康案例

