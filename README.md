# RightsWindow · 授权窗口编排与替换演练台

面向品牌内容团队的本地演练工具：按 **地区 × 渠道 × 当地时间** 查看节目段落的素材使用权，
编辑授权窗口与替代素材链，并拖动 **演练时钟** 观察生效前、临界时刻与失效后的实际选材。
全部在浏览器本地运行，无任何后端依赖。

## 运行

```bash
npm install        # 如遇缓存目录权限问题：npm install --cache /tmp/npm-cache
npm run dev        # 开发服务器
npm run test       # vitest：52 个测试
npm run build      # tsc -b && vite build 生产构建
```

## 功能一览

- **三地区 × 三渠道**：上海 / 新加坡 / 伦敦（含 BST 夏令时），电视 / OTT / 社交短视频。
- **时间轴**：每个段落按替代链分泳道展示授权窗口；虚线框为播出时段，红色斜纹为空档，
  琥珀色为重叠；点击 / 拖动任意位置移动演练时钟。
- **演练时钟**：UTC + 三地本地时间同框；滑杆、±1 秒/10 秒/1 分钟微调、
  「关键时刻」一键停靠（窗口边界、播出边界、冲突边界），←/→ 键（Shift 加速）也可微调。
- **选材路径**：逐步解释每一环为什么跳过（未授权 / 未覆盖 / 断裂 / 循环）、
  重叠时按什么规则决胜、最终选中了哪份素材。
- **冲突检测**：授权重叠、授权空档、地区不匹配、替代链断裂、替代链循环，
  均定位到受影响段落与时间段，并可一键跳到临界时刻。
- **编排**：窗口（地区本地时间编辑，自动换算 UTC）、替代链（排序 / 增删）、素材库。
- **方案管理**：草稿自动保存（刷新恢复）、撤销 / 重做（50 步）、情景快照、一键复位（可撤销）。
- **确定性**：选材与冲突检测均为纯函数，同一输入重复演练结果完全一致（有测试保证）。

## 内置案例：Aurora 品牌全球直播（2026-09-20）

12:00–13:00 UTC（上海 / 新加坡 20:00，伦敦夏令时 13:00），四个段落，
替换链为「主片 → 区域版（亚太 / 欧洲）→ 安全垫片」。案例刻意包含：

1. **授权重叠** — 主直播上海 OTT「基础授权」与「临时延授」在 12:20–12:35 同时生效；
2. **授权空档** — 栏目片段上海 OTT 主片 12:55 提前失效，且链上未挂安全垫片；
3. **地区不匹配** — 广告时段在伦敦完全未授权；
4. 常规替换 — 新加坡 OTT 主片 12:25 提前失效后落到亚太区域版；伦敦 OTT 主片未授权走欧洲区域版。

## 关键规则

- 窗口为半开区间 `[开始, 结束)`：开始时刻立即生效，结束时刻立即失效。
- 重叠决胜：优先级高 → 开始早 → ID 字典序。
- 内部一律以 UTC 毫秒计算，仅在展示 / 编辑时换算地区本地时间（基于 `Intl`，含夏令时）。

## 代码结构

```
src/
  domain/          纯函数领域层（无 React、无 Date.now）
    types.ts       模型：段落 / 素材 / 授权窗口 / 替代链
    time.ts        时区换算（Intl，UTC↔本地，偏移标签）
    resolve.ts     选材解析引擎（决策路径 + 跳过原因）
    conflicts.ts   冲突检测（重叠 / 空档 / 不匹配 / 断裂 / 循环）
    edit.ts        文档编辑操作（纯函数，供撤销栈使用）
    seed.ts        内置直播案例
    explain.ts     路径解释文案
    view.ts        可视范围与关键时刻
  state/store.ts   草稿持久化、撤销重做、快照、复位
  components/      TopBar / ContextBar / SegmentList / Timeline /
                   ClockControls / ResolutionPanel / ConflictList / Editors …
  **/__tests__/    vitest：时间边界、时区换算、冲突解释、替代链、store、App 冒烟
```
